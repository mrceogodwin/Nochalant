# Nochalant Club

Premium dark social club. 18+.

Your people. Your scene. Your rules.

This repository is the current app: onboarding, home, discover, chats, gifts, voice, Club ID, and the rest of the club surfaces. It replaces the previous code in this repo.

Local data lives in the browser. Sign-in, payments, and live multiplayer are not wired yet.

## Run

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
